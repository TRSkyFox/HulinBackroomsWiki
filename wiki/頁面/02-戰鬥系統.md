# 02 戰鬥系統

[← 回目錄](README.md)

戰鬥是**回合制**：遭遇 → （部分敵人有）**戰鬥開始的檢定** → **先攻排序** → 輪流行動 → 戰利品。
回合推進時畫面用 `——第 N 回合——` 粗體分行標示，頂部固定顯示 `第 N 回合` 標籤與**先攻順序條**。

> **本頁的資料來源（單一事實來源）**
> - **戰鬥機制**（先攻、行動選項、逃跑、縮放、敵人卡）→ `_data/battles/`
> - **敵人本體與技能**（含實測樣本、變種前綴）→ `_data/enemies/`（本體是 `type: entity`，所以屬於實體圖鑑）
> - **難度** → `_data/difficulties/`、**前綴** → `_data/prefixes/`
>
> 下面所有清單都用 **list／table 查詢語法**（建置期展開）**查詢產生**，改資料就會跟著變；
> 敵人資料**只寫一份在圖鑑**，本頁只引用或查詢，**不重複寫**。

## 一、開戰與先攻

### 1.1 先攻公式（現行畫面原文）

> 先攻 = `d20 + 敏捷 + 裝備加成 + 特殊能力加成 + 身上狀況加成`

{{table: battles kind=initiative cols=name,formula,tie,chain}}

### 1.2 行動順序規則

- **同分時隊友先。**
- **順序連在一起的隊友，會一起連行動。**
- 每個單位在面板上標示狀態：`已行動`／`行動中`／`等待中`。
- 頂部固定顯示 `第 N 回合` 標籤 ＋ **先攻順序條**：
  `嗡鳴體A 16 | 玩家 15 | 嗡鳴體B 13`
- 新回合以**粗體分行**標示：`——第 2 回合——`、`——第 3 回合——`（見 {{ref: battle-回合}}）。

**實測樣本**

| 難度 | 單位 | 擲出 | 加值 | 先攻 | 狀態 |
|---|---|---|---|---|---|
| 簡單 | 嗡鳴體A | d20 15 | +1 | **16** | — |
| 簡單 | 玩家（玩家） | d20 7 | +8 | **15** | — |
| 簡單 | 嗡鳴體B | d20 12 | +1 | **13** | — |
| 真正的后室 | 玩家（玩家） | d20 6 | +8 | **14** | 行動中 |
| 真正的后室 | 回聲人影B | d20 4 | +1 | **5** | 等待中 |
| 真正的后室 | 不死飢餓的回聲人影A | d20 2 | +1 | **3** | 等待中 |

- 玩家的 `+8` 是**敏捷 ＋ 裝備 ＋ 特殊能力 ＋ 身上狀況**的合計（畫面只給合計值）。
- 敵人的加值樣本都是 **+1**，但只有兩隻敵人、兩個難度，**不足以當規則**。

> ⚠ **與舊紀錄衝突（保留歷史）**：舊頁面曾記「先攻 = d20 + 裝備／天賦先攻加值，**敏捷本身不直接加在骰上**」。
> 現行畫面明列 `+ 敏捷`，兩者衝突。依 ARCHITECTURE §0 規則 6（遊戲內文本 > 實測），**以現行畫面為準**；
> 舊記載不刪除，留在 {{ref: battle-先攻}} 條目裡當歷史紀錄。

### 1.3 戰鬥開始的檢定

部分敵人開場會要求玩家做**魅力檢定**（原文「直視它的瞬間，你得穩住自己」）。

{{table: battles kind=opening-check cols=name,check,samples}}

| 難度 | 檢定難度 | 失敗 |
|---|---|---|
| **簡單** | 12 | 理智 **−2** |
| **真正的后室** | 17 | 理智 **−1** |

> ⚠ **失敗懲罰不是單調放大**（−2 → −1）→ 不可以寫「難度越高越痛」。
> 各敵人的開場文本與自己的樣本放在各自的技能條目（例：{{ref: enemyskill-嗡鳴體-開場檢定}}）。

### 1.4 敵人卡與敵人數量

{{table: battles kind=enemy-card cols=name,effect,limit_game}}

- 敵人卡顯示：**名字**、**HP `x/6`**（血條）、**防禦 11**。
- **遊戲畫面**：一頁最多同時顯示 **6 個**敵人；正常不超過 6 個，
  **但 6 人以上一同遊玩時敵人數量無上限**。
- **Wiki 沒有 6 個上限**，照實際資料全部列出。
- `A`／`B`／`C` 只是**同一場戰鬥裡的多個個體**，同一個敵人只建**一個**條目：
  {{ref: entity-嗡鳴體}} 的 `嗡鳴體A`／`嗡鳴體B` 寫在它的 `aliases`。

### 2.1 逃跑（補充）

- 檢定為**敏捷**；畫面原文：`敏捷檢定 難度12，你的加成 +6（敵人越多越難跑）`。
- **成功就脫離這場戰鬥，拿不到戰利品。**
- 難度樣本：**簡單 12**、**真正的后室 18**、舊紀錄 10 → 明寫「**敵人越多越難跑**」，
  每多一個敵人加多少**尚無資料**。
- 裝備／狀態會加減逃跑：`狂暴的大笑的房客` 場景中 `逃跑 −2`；
  `撤退路線` 技能可讓自己與願意跟的隊友 **敏捷 +5** 逃離戰鬥。
- **失敗會怎樣：尚無資料**（沒有拍到失敗樣本）。
- 完整樣本見 {{ref: battle-行動-逃跑}}。

### 2.2 攻擊（補充）

- 攻擊選項會直接寫出**當前武器、傷害骰、吃的屬性、耐久**：
  `雙手：生銹的水管，傷害 1d6 鈍擊（力量），耐久 6/6`。
- 舊紀錄另有「**選擇右手／左手**武器攻擊」的版本（見 [04 物品與裝備 §雙持](04-物品與裝備.md)）。
- 詳細欄位見 {{ref: battle-行動-攻擊}}。

## 三、命中與防禦

攻擊是 `d20 + 命中修正` 對抗目標的**防禦值**：

```
攻擊獵犬（防禦 12）
R 4+5=9 失敗 → 9 < 12，沒打中
R 18+5=23 成功 → 不只命中，還喊出「命中！」
```

敵方攻擊則顯示為 `〔攻擊方 攻擊 防禦 N〕` 或 `〔某怪 X 攻擊 防禦 N〕`：

```
〔獵犬咬 防禦 10〕
〔攻擊 防禦 14〕用雙手握著的紅黑拳套攻擊敏捷的竊皮者：擲出 18 + 3
〔敏捷的竊皮者撕抓 防禦 11〕敏捷的竊皮者撕開那張人皮……抓向擲出 6 + 6
```

### 命中結果

| 結果 | 紀錄中的寫法 |
|---|---|
| 未命中 | `沒打中`、`失敗` |
| 命中 | `命中！`、`造成 3 傷害（獵犬剩 5 / 8）` |
| **重擊**（自然 20） | `重擊！！體力．9、理智．2` |

實測的完整判定格式：

```
〔攻擊 防御11〕玩家 用雙手握著的生銹的水管攻擊 嗡鳴體A：擲出 19+0=19 → 命中！
（1d6 鈍擊） 造成 3 傷害（嗡鳴體A 剩 3/6）
「鏗」的一聲，金屬砸下去，還在嗡嗡地響。
```

## 四、傷害

傷害 = **武器骰 + 屬性修正 + 等級加成**，並帶有**傷害類型**。
畫面會在武器旁直接寫出算式，例如 `攻擊 右手 1d6+3 鈍擊／左手 1d2+3 鈍擊`。

### 傷害類型

| 類型 | 例子 |
|---|---|
| **鈍擊** | 大扳手 `單手近戰鈍擊 1d6（力量）`、拳頭 `1d2`、鐵鎚 `1d6（力量）`、鍋蓋 `1d2（體質）` |
| **揮砍** | 美工刀 `單手近戰揮砍 1d4（敏捷）`、手術刀 `1d4（智力）` |
| **火焰** | 火把 `單手近戰火焰 1d4（力量）` |
| 遠程／射擊 | 需消耗**彈藥**（「一份 6 發」「一份 8 發」） |

> 注意：不同武器吃**不同屬性**——這是本作很有特色的設計。美工刀吃敏捷、鍋蓋吃體質、手術刀吃智力。
>
> ⚠ **括號裡的屬性只是「算傷害用哪個屬性」，不等於屬性加成。**
> 例：**美工刀**寫「（敏捷）」，但**不會給你敏捷 +1**（2026-10-14 已削弱）。
> 真正加屬性的寫在裝備欄，例如棉紗工作手套「力量 +1」。

### 等級加成

`等級加成：體力、理智上限 + N，命中、傷害 + N`（N = 等級 - 1），
所以 3 級角色的武器算式會變成 `1d6 + 3`（基礎 +2，再加等級 +1）± 裝備。
詳見 [01 核心機制 §5](01-核心機制.md#五經驗與等級)。

### 武器耐久

- 每把武器有耐久：`大扳手（耐久 27 / 28）`、`耐久 28 / 28`、`耐久 10`、`耐久 8`、`耐久 6`。
- 特定技能會**額外消耗耐久**（如「撬擊」「雙持攻擊」「電擊陷阱」）。
- 耐久歸零武器會壞掉。
- **武器脫手**：攻擊失敗可能觸發 `手一滑，「大扳手」飛了出去，匡啷一聲掉在腳邊。（武器脫手了：用「切換武器」撿起來重新拿好）`

## 五、武器技能（Weapon Skills）

每把武器自帶技能，選單會標出來源，例如「砸凹（大扳手）」「亂刺（美工刀）」。

| 技能 | 效果 |
| --- | --- |
| **砸凹** | 瞄準外殼砸下去（**命中 -1**）：砸中則目標**防禦 -2**（最多 -3，整場有效），多消耗 1 耐久 |
| **撬擊** | 找縫隙撬下去：**命中 +4**，但**傷害 -1**、多消耗 1 耐久（對付很硬的東西） |
| **亂刺** | 不管三七二十一地亂刺：**隨機攻擊三下**（可能打到同一個） |
| **雙持攻擊** | 兩隻手的武器**各攻擊一次**（每下 **命中 -1、傷害 -1**，耐久照扣）；遠程武器改成射擊，要用彈藥。刺完喘不過氣（**防禦 -2**） |
| **舉盾掩護** | 把盾舉到大家前面：自己防禦，**其他隊友防禦 +2**，直到你下次行動開始；本來會打中、靠舉盾才沒打中的每一下，**盾耐久 -2**（可能當場壞掉） |
| **強光照射** | 手電筒技能（手電筒本身 `感知 +1`）：**所有敵人下一次行動命中 -5**（會被光吸引的也有效） |
| **火焰揮擊** | 火把技能 |
| **精準切割 / 放血 / 架開 / 橫掃** | 其他武器技能（效果待補全） |
| **勾住** | 開山刀（耐久 30）：**命中 +1、傷害 -1**；勾中的話把它**拖過來**，這場戰鬥**所有人打它命中 +3** |
| **壓制打擊** | 折疊椅（雙手近戰鈍擊 1d8 體質、耐久 18、休息時理智 +1）：**命中 +3** 的近戰攻擊，命中時讓敵人**錯過下一次行動**（每場一次） |
| **指出弱點** | 守望者徽章（飾品）：說出這個實體的弱點，這場戰鬥**所有人打它命中 +3**（每場一次） |
| **變形斬** | 利波瑞特（斧模式）：可以切換**斧／劍**（⚠ 效果原文未完整找到） |
| **解放** | 利波瑞特：⚠ 只讀到技能名，**效果未找到** |

## 六、戰鬥中的其他規則

| 規則 | 內容 |
| --- | --- |
| **保持距離** | 遠程武器「拉開距離」＝**防禦 +2**；**一旦衝上去近身就永久失去**（`衝上去近身——保持距離的防禦 +2 沒了`）。它也是戰鬥中的一個可投票選項（畫面出現 `保持距離 投票請離開`） |
| **暈眩／倒地** | 目標**錯過下一次行動**（`暈眩中`；`扑了個空，重重地摔在地上`） |
| **打暈可打斷蓄力** | 敵人的蓄力招式可以**打暈打斷**；畫面提示 `打暈可打斷；先閃避或防禦`、`先防禦` 也是可行選項 |
| **敵人同名以 A／B／C 區分** | 同一種敵人會加上 **A／B／C** 後綴，**A／B／C 只是同一場戰鬥裡的不同個體**（不是不同條目）；**變種前綴**另外寫在名字前面，見 §九.3 |
| **敵人特性實例** | `不死的：傷口每回合都在愈合`、`嗜血的：打中人就會恢復`；弱點標記如 `怕電擊／不怕穿刺／怕揮砍／很怕火焰` |
| **敵人也能重擊** | 「重擊」是敵我共用的標記：`〔敏捷的礦坑游牧民 A 重擊 防禦 14〕` |
| **最後一回合** | 回合數到頂時畫面提示 `最後一回合了——出口就在附近！` |

> 貼上去近身會**永久失去**「保持距離」的防禦 +2——這是選擇近戰時常被忽略的成本。

## 七、職業戰鬥技能（每場一次）

每個「特殊技能」都會附帶一個**每場戰鬥只能用一次**的戰鬥技能。
完整清單見 [03 角色與技能](03-角色與技能.md)，這裡列實際用過的：

| 技能 | 效果 |
|---|---|
| **電擊陷阱**（機械維修） | 地上佈滿通電的線：每個敵人各擲一次命中（**智力對上防禦**），踩到的受 `2 + 智力 ÷ 2` 傷害（每升一級 +1）。電從手上的近戰武器走：它 **-3 耐久**，每多一個目標再 -1；手上沒有近戰武器則**自己被電**。 |
| **咬牙撐住**（野外求生） | 自己回復 `3 + 體質 ÷ 2` 體力，並**擺出防禦姿勢**。 |
| **撤退路線**（方向感） | 指出退路：自己和願意跟著走的隊友 **敏捷 +5** 嘗試逃離戰鬥。 |
| **緊急處置**（急救訓練） | 替狀況最差的隊友回復 `4 + 智力 ÷ 2` 體力、**1 理智**。 |
| **跟著一起笑**（魅力型應對） | 魅力檢定成功可讓敵人**離開戰鬥**（`強壯的大笑的房客 A 離開了戰鬥`）。 |

> 已用過的同一個技能會顯示「**這場戰鬥已經用過了**」而不能再用。
> 其他批次補到的戰鬥技能集中在 §十三。

## 八、戰鬥中的理智

戰鬥不只看體力，**理智也會被打**：

```
重擊！！體力．9、理智．2
體力．5、理智．1、陷入「耳鳴」
理智．2
```

部分裝備專門減少這種傷害：`毛線帽 … 戰鬥中理智傷害 -1`、`戰鬥中理智傷害 -1、魅力 +1、技能：放首歌`。
詳見 [05 狀態與異常](05-狀態與異常.md)。

> ⚠ **注意「戰鬥中」三個字**：上面這些**只在戰鬥中生效**。
> 目前唯一**戰鬥外也有效**的是飾品 **碑石護符**（**理智傷害 −1**，
> 由 `方尖碑碎片 ＋ 繩子` 合成）——面對**事件與場景造成的理智傷害**時差別很大。

戰鬥勝利後出現**戰利品**，多人時每人可以按「想要」表態：

戰利品：獵犬的牙 想要的人按「想要」。

## 十一、計量條、難度與區域名

> 場景標題結構為：
> `### 第 N 層《<難度>《<計量條或類型標籤>：<名稱>《<場景>`
> 本節把**難度**、**計量條**、**區域名（類型標籤）** 三者徹底分開。
> 各難度的獨立條目見 §九.3 的難度查詢表（`_data/difficulties/`）。

### 11.1 難度倍率

| 難度 | 結算倍率 |
| --- | --- |
| `困難` | **×1.4** |
| **`惡夢`** | **×1.7** |

- 結算畫面原文把 `惡夢` 與 `困難` 並列為同一種東西：`難度「惡夢」× 1.7`。
- ⚠ **`惡夢` 是難度，不是計量條**——判定的關鍵是：`惡夢` 那格**可以完全沒有方塊**
  （例：`第 1 層丨困难丨岔路`），而方塊只跟著計量條名出現。
- 另有 **`簡單`** 與 **`真正的后室`**（戰鬥樣本見 §一）、**`普通`**（只拍到建立角色畫面）；
  這幾個的**結算倍率尚無資料**。

| **武器脫手** | 攻擊擲出 **1** 時：「手一滑，武器飛了出去，匡啷一聲掉在腳邊。（**武器脫手了：用「切換武器」撿**）」 |
| **兩隻敵人同時攻擊同一人** | 兩下都命中時，體力扣減**分開**顯示（例：`體力 −2`、`體力 −4`） |
| **戰鬥中救回隊友** | 「倒下的那一瞬間，還來得及！身上有救命道具的人，要不要現在就用？」→ 指定道具（本批是 **濃縮杏仁水**）救回：**體力 +2、理智 +3** |

### 14.5 本批的戰鬥規模觀察

- 本批最大的一場是 **Level 1 的 `死亡飛蛾 A～E` 五隻**，先攻順序一次排出 **13 個人／單位**
  （例：`死亡飛蛾 A 23 → 玩家 18 → 玩家 16 → 玩家 15 → 死亡飛蛾 C 11 → … → 玩家 3`；
  **只有敵人與隊友的角色會顯示名字，玩家帳號名一律寫成 `<玩家>`**）。
- 本批**至少 3 名隊員在戰鬥中倒下並被救回**（用濃縮杏仁水），符合既有的「倒下 ≠ 出局」規則。
