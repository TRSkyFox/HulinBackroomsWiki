## 一、裝備欄位

角色有一組固定裝備欄（畫面上以 `[ 欄位名 ]` 顯示）：

```
[ 頭部 ] [ 身體 ] [ 手套 ] [ 斗篷 ]
[ 腳部 ] [ 腰間 ] [ 飾品 ] [ 背包 ]
[ 右手 ] [ 左手 ]
```

- **右手／左手**是兩把**獨立武器**，可以雙持（見 [02 戰鬥系統 §5](02-戰鬥系統.md#五武器技能weapon-skills)）。
- **背包**有格數上限，預設 **10 格**，可由裝備或永久能力擴充。
- 「身上穿戴的東西要先拿下來」才能拿去合成（手上的武器可以直接放上去）。

## 六、強化與合成（工作台）

背包中有「**合成**」功能，畫面說明原文：

> - 挑兩三樣東西放上工作台，拼拼看。**配方不會寫出來，要自己試。**
> - **至少要放兩樣東西。**
> - 對的組合會做出新東西；不對就拼不起來，**東西會還給你**。
> - **武器 + 強化用的東西（磨刀石、燈油……）= 強化那把武器。**
> - 身上穿戴的東西要先拿下來（手上的武器可以直接放上來）。
