### 環境

> 游了很久、很久。河變窄了，水變冷了——冷得剛剛好，好像有一股從很遠的地方吹來的風。
> 穿過那片倒影的時候，水一下子變冷了——不對，水不見了。

> 推開艙門探出頭——外面是海。無邊無際、平靜得不像話的海，上面罩著一層白色的濃霧。

> 這座鐵皮碉堡就這樣漂在海中間，一動也不動。舔了舔嘴唇上的粉末，臉色變了：「……這是骨頭。」

> 白色的粉末一直從霧裡飄下來，落在頭髮上、睫毛上。一直忍不住咳嗽。

### 機制特色（原文）

- **「漂遠了」計量**：場景標題帶一串點／圈，像漂流距離條，隨推進增加：`漂遠了．．．OOO`。這是繼 Level 6「距離」之後第二個帶距離階段的樓層。
- **強制倒數**：畫面顯示「強制倒數：關」。
- **骨頭粉末**：白色粉末從霧裡飄下來會讓人咳嗽；把碉堡的門窗縫塞好就能解除。
- **沖散與會合**：大浪會把隊伍隨機沖到不同地點（碉堡／霧裡／抓著木板），之後要「先到約好的地方，靠著牆等另一邊的人」。
- **孤島式據點**：鐵皮碉堡是這一層唯一的休息點（上鋪、火爐、艙門）。
- **隱藏察覺選項**：感知型角色才看得到的 `（只有你察覺到）` 選項大量出現。

### 已知場景／事件（原文）

| 場景 | 內容 |
|---|---|
| **斷崖** | 腳下的海床很淺，水只到腰；再往前一步，海床就沒了——一道垂直的斷崖，往下是深得發黑的海，什麼都看不到。斷崖邊的岩石上卡著一個生鏽的鐵盒。`趴在斷崖邊把鐵盒撈上來（敏捷 難度18）｜往斷崖底下看一眼｜退回淺灘`。 `18+4=22` 成功 → 得到「杏仁水」「急救包」，鐵盒裡的紙條寫著：「**不要往下看。**」 |
| **大浪（沖散隊伍）** | 「平靜的海面突然隆起——是那個東西翻了個身。一道大浪打過來，把你們的筏掀翻了。」隊伍被沖散：「漂到了霧裡」、「被打回了碉堡」、 |
| **碉堡一角的小火爐** | 碉堡角落有人留下一小堆東西和一個小火爐，爐子上擺著一塊肉，旁邊寫著：「別煮。」`把補給收好｜太冷了，把爐子點起來取暖`。點火 → 「爐火一點起來，好暖。可是那塊肉開始滋滋作響——裡面有東西在動。」 體力 -1、理智 -2 |
| **上鋪** | 碉堡裡的上下鋪，上鋪沒泡到水；你們擠在上鋪上把濕衣服擰乾、互相靠著取暖。`擠在一起睡一覺｜把碉堡的門窗縫都塞好，再休息`。塞縫 → 「骨頭粉末終於不再飄進來，大家的咳嗽也慢慢停了。」 體力 +2、理智 +2 |
| **漂流** | `什麼都不想，就這樣漂著`；划著從碉堡拆下來的木板前進：「霧很濃，濃得看不見三公尺外。」、 |
| **手指動了一下／越漂越遠** | 場景名「手指動了一下」；`手牽著手，一起往回划｜跟著最近的那艘船走` |
| **一艘小船／大船的影子** | `上船，一直划出去｜沿著岸邊划一會兒｜拿走船上的水壺`；`往霧裡那艘大船的影子划｜跟著一塊漂流的木頭走｜回到碉堡裡休息一下` |
| **隱藏察覺** | 「（只有你察覺到）水邊綁著一艘小小的木船，船上有槳。」；「（只有你察覺到）那個招手的人……動作一直沒有變過。」 |
| **出口：溫的海水** | `跳進那片比較溫的海水`（選項全文：「有一片海面冒著白白的熱氣，海水摸起來竟然是溫的」）→ 「你們跳進溫溫的海水裡，往下沉、往下沉——浮起來的時候，四周是一圈石頭，熱氣一直往上冒。抬頭一看：雪山。是一座溫泉。」走出這一層 |
