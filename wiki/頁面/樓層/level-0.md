## 一句話

黃壁紙、濕地毯、日光燈的嗡嗡聲——後室的原點。

## 機制

- **出口進度 15**。走到走廊盡頭推開寫著 `EXIT` 的門即可離開。
- **岔路流程**：每次事件結束按「繼續」→ 顯示當前出口進度 → 進入下一個岔路。
- **區域會重複**：黃色房間會不斷重現，同一個房間可能走過很多次。

- **第 16 層的「出口的門」**：走廊盡頭兩扇門，一扇綠色亮著「出口」，另一扇後面是黃色壁紙與濕地毯——「**舊的那一個**」；選錯會回到同一層。
- **手繪地圖／不存在的街道地圖** 可以在地毯上攤開，對照牆上記號「找到一條更近的路」，直接加出口進度（+2）。
- 本場次出現「**Level 1.5「潛伏的危機」**」的橫幅（⚠ 編號可疑，可能是 OCR 誤讀），其描述「這裡像停車場，又不太像……有些區域亮著燈。更多的區域，是一片完全的黑」，與 Level 0 的房間並列出現。

第一批補充的機制：

- Level 0 的招牌會在畫面上**一直重複出現**（同一層出現 10 次以上的 `## Level 0 「大厅」` 標題），這是紀錄中判斷換層的雜訊來源。
- 沿著這一段，Level 0 也能「不滿進度就離開」：8/15 就走進 EXIT 門。
