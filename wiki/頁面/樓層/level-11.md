### 補充

**環境（本場次的完整描述）**

> 大樓。一棟接一棟，高得看不見頂，灰撲撲的水泥牆面上，窗戶一格一格地排下去，每一格都是黑的。
> 空氣很髒。一股汽油、廢氣和灰塵的味道，吸一口喉嚨就發癢。霧霾把整座城市罩成一片黃灰色，
> 遠處的大樓只剩下模糊的輪廓。路口的紅綠燈在亂閃——紅、綠、紅、黃、綠、綠、紅，沒有規律。
> 路牌上寫著：「往這邊往那邊」「本路不通往本路」。到處都是人留下的痕跡：塗鴉、輪胎痕、
> 被風吹得滿地跑的垃圾。**可是兩個人都沒有。一隻鳥都沒有一棵活著的草都沒有。**

> **一棟大樓的外牆上，用紅色的噴漆寫著好大的字：「不要進去」。旁邊用藍色的噴漆寫著：「一定要進去」。**

**街區分段**（`街區：密密麻麻的街區` → `街區：紅磚的街區` → `街區：灰色的公寓群`）

- **密密麻麻的街區**：黑窗高樓、亂閃紅綠燈、看不懂的路牌
- **紅磚的街區**：「街道變寬了。招牌上的字一個一個不見了，大樓換成一棟一棟紅磚砌的公寓，
 **每一棟的正中間都掛著一座黑色的鐵製逃生梯**。路口的消防栓生鏽了。」「磚縫裡長的東西，不是草。」
- **灰色的公寓群**：「一塊一塊預鑄的水泥板拼起來，每一層一排一模一樣的小陽台，有的陽台上還晾著褪色的衣服。**每一棟都一模一樣。你們已經分不出來，剛剛是從哪一棟旁邊走過來的。**」

**新場景／事件**

| 場景 | 內容 |
|---|---|
| **最高的樓頂（交付委託）** | 比四周都高出一大截的大樓，電梯不動只能爬樓梯——「一層、兩層、三十層、五十層」。推開頂樓的門，風灌進來，「四面八方都是樓，一直延伸到看不見的地方」。`爬上水塔，把標插在最高的地方（力量 難度18）`／`就插在頂樓的欄杆上吧`。選欄杆：標綁在欄杆上，**不是最高的地方，可是發報器的燈還是亮了**（委託完成，記憶碎片 +12） |
| **兩棟大樓** | 兩棟一模一樣的大樓並排，中間只隔一條窄巷。左邊大門開著、樓梯往上；右邊大門半掩、有往下的坡道通往地下停車場。**霧霾很濃，兩棟的頂樓之間好像有一座天橋。** 走上左棟：每一層走廊都一樣（一排門全部關著），**爬到十幾樓時樓梯斷了——上面的樓梯憑空少了一截**。`從走廊找別的樓梯（智力 難度18）`失敗（7+5=12）：「每一層都一樣，每一扇門後面都是牆。」 |
| **還能鎖上的公寓** | 門鎖是好的、窗戶關得緊緊的，霧霾進不來。舊沙發、桌子，**桌上擺著一個空碗，好像有人吃完飯就走了**。「在這座髒兮兮的城市裡，這是第一個能好好呼吸的地方。」`鎖好門，好好休息`／`翻翻廚房`。翻廚房：櫃子裡有幾罐罐頭和一罐咖啡（得到「罐頭」「咖啡」；**咖啡：理智 +1、口渴 +2、治好「疲憊」**） |
| **滿是花盆的陽台（新委託）** | 二樓陽台擺滿花盆，一個老人拿著澆水壺慢慢一盆一盆澆，看到你們招了招手。**「這些花，一直開不好。這裡的光是假的。」** 他拿出一小包種子：「下面那一層有麥田，那裡的光……也許是真的。可以幫我種下去嗎？我走不動了。」選項：`收下種子，答應他`／`我們不會往那邊走`／`趁他不注意，走陽台上的東西（敏捷 難度17）`。答應→**委託「向陽花的種子」**：到 Level 10 的麥田找一塊曬得到光的地方種下，再回 Level 11 告訴他（所有人理智 +1） |
| **巷子裡的歌聲** | 兩棟大樓之間很窄的巷子，盡頭掛著一盞紅燈籠，巷裡傳出一個女人的歌聲——很慢、很好聽，是一首很老的歌。燈籠底下有一扇玻璃門，門上貼著紅底金字的春聯。選項：`推開那扇玻璃門`／`聽聽那首歌`（本場次選「走開」：**大家快步走過巷口。歌聲跟著走了一段，然後停了。**） |
| **空蕩蕩的小餐館** | 紅色皮沙發卡座、鉻色吧台、牆角一台點唱機，霓虹招牌還在閃，「可是店裡一個人都沒有」。**吧台上的盤子裡的東西早就變成了一層灰。** 收銀台旁有一個裝小費的玻璃罐。選項：`翻翻廚房`／`坐在卡座上休息一下`／`拿走小費罐裡的錢`。翻廚房：冰箱是空的，櫃子裡還有幾罐沒過期的罐頭和一包咖啡豆（得到「罐頭」×2） |
| **巷子裡的垃圾堆** | 壞掉的家電、生鏽的腳踏車、一袋一袋的塑膠袋——「像是曾經有很多人住在這裡，每天丟出來的東西。**可是這座城市裡，從來沒有人。**」`小心地翻一翻（感知 難度18）`。失敗（4+6=10）：**一根生鏽的鐵絲劃破了手，傷口沾滿了灰 → 體力 -2、陷入「感染」** |
| **一直往下的鐵梯** | 大樓外牆有一道鐵梯一路往下，伸進人行道上的方形洞口。**洞口底下傳來嗡嗡的聲音——很大、很規律，像很多很多機器在同時運轉。** `往下爬一段看看（體質 難度18）`／`不要靠近那個洞`。選「不要靠近」：繞過洞口，嗡嗡聲在背後響了很久 |
| **窗台上的盆栽** | 一扇窗台上擺著一盆植物，綠油油的一一「在這座什麼都是灰色的城市裡，綠得刺眼」。**你們看著它的時候，葉子開始捲起來、變黃、變黑。不到一分鐘，整盆都爛成了一灘黑色的泥。**「一定是有人剛剛才放在這裡的。」`找找放盆栽的人（感知 難度19）`。成功（16+6=22）：**窗戶後面的房間裡有一個剛打包好的背包，主人不在。背包上掛著一張紙：「每天帶一盆進來。總有一天會有一盆活下來。」** 你們沒有動背包，只拿了旁邊多出來的補給（「瓶裝水」＋「暖暖包」） |
| **粉紅色的光** | 兩棟大樓之間的小巷子底有一團光——粉紅色的、橘色的、暖暖的，像夕陽。**「可是這裡的天空從來沒有夕陽。」** 光旁邊有一張長椅。`在長椅上睡一下`／`坐著休息，不要睡著`。選坐著：靠著暖暖的光休息，有人打了好幾次瞌睡都被搖醒（所有人體力 +2、理智 +1） |
| **一直在震的門** | 有一扇門一直在震，門板咚、咚、咚地抖，**門縫裡漏出好大好大的音樂——鼓、吉他、尖叫，全部混在一起，大得連地板都在晃。把手摸起來麻麻的。** `打開門`／`把耳朵貼上去聽`（本場次選「離開」：大家快步走開，門一直在震，震到很遠很遠的地方都還聽得到） |
| **城市的邊緣（出口）** | 大樓突然變少，眼前兩條路：一條窄巷，**巷子盡頭柏油路變成泥土，聞得到麥子的香味**；另一條路正中間有**一個被推開一半的人孔蓋，底下冒著熱熱的白色蒸氣，傳來管線敲打的聲音**。選項：`走進那條巷子（回 Level 10）`／`爬下人孔（全員力量 難度15）`／`開上那條寫著「10」的高速公路`／`回去找探勘隊的隊長（交付「最高的樓頂」）`／`先不走，再多探索幾步` |

**已知敵人**：本段紀錄**未出現戰鬥**，未觀察到敵人。⚠ 本頁原本的紀錄記載的「往霧比較淡的地方走」是安全路線，
本場次新增的危險則偏向**環境傷害**（鐵絲感染、斷裂樓梯、斷電嗡嗡聲）。

**新機制**

- **「一律相同」的空間迷向**：灰色的公寓群每一棟一模一樣，「你們已經分不出來，剛剛是從哪一棟旁邊走過來的」
；兩棟大樓的樓梯則會**憑空少掉一截**。
- **光與綠色是稀缺資源**：整座城市「一棵活著的草都沒有」，所以陽台上的花盆與窗台的盆栽
成為唯一的綠，而盆栽會在眼前腐爛。
- **本層承接 Level 10 的跨層委託**，且完成後**必須回到 Level 10 的帳篷交付**
- **第二次經過本層（第 14 層）**：從 Level 69 的「很長很長的巴士」下車後又回到這裡
 （起，`街區：密密麻麻的街區`，
）——⚠ 該段屬於分配範圍的邊界，內容未完整查核。
