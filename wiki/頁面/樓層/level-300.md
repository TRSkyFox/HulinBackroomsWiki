### 環境

> 細細的坑道，寬度剛好夠一台礦車過。兩邊的木頭支架歪歪斜斜，有的已經裂開了。

> 鐵軌在這裡分成三條。左邊的鐵軌是新的，亮亮的；中間的鏽得很厲害；右邊的鐵軌上，有一道一道深色的痕跡，一路延伸進黑暗裡。

> 鐵軌到這裡就斷了。前面有三個方向：一道往上的鐵梯，梯子頂端有一扇綠色標誌的鐵門；一條很窄的岔道，裡面傳來嘩啦嘩啦的水聲；還有腳底下這一塊地面——踩起來，空空的。

### 機制特色（原文）

- **光線是主要資源**：煤油提燈、燈油（可合成燃燒瓶）；「暗的地方，聲音特別清楚。」
- **深度階段**：場景標題固定帶 `深度：淺層`，同一個礦坑有明確的縱深分層。
- **三選一的方向感**：幾乎每個岔路都是「順著鐵軌／跟著滴水聲／往有風的地方」，用感官取代地圖。
- **飲水風險**：礦坑裡的積水會造成「中毒」，是全紀錄中明確的環境異常來源。
- **通風小洞**：小房間牆上有人鑿了通風的小洞，對應「空氣不太悶」的敘述。

### 已知場景／事件（原文）

| 場景 | 內容 |
|---|---|
| **三條鐵軌** | `走新的那條｜走鏽掉的那條｜走有痕跡的那條`。走新的那條 → 通到一個小平台，平台上有人留了一盞燈和半罐燈油（得到「燈油」，全員理智 +1） |
| **木板隔起來的小房間** | 門口掛「休息室」牌子，裡面有木頭長椅、鐵皮火爐，牆上掛著幾頂安全帽；有人在牆上鑿了一個通風的小洞。`在長椅上睡一下｜生起火爐｜看看牆上的安全帽`。生火 → 全員 體力 +2、理智 +2 |
| **白白的水** | 坑道地面往下陷，積了一大灘水：水是白濁的，水面上漂著一層細細的泡沫，邊緣的石頭被泡得滑滑的。`捧起來喝｜滑滑的，不太對——不要喝`。喝了：「水滑滑的，像肥皂水。才喝了一口，嘴巴、喉嚨就開始燒——燒得像吞了一把火。」 體力減少並陷入「**中毒**」 |
| **坑道的盡頭（出口）** | `爬上鐵梯，推開那扇門｜跟著水聲走｜用力跺腳（力量 難度15）｜先不走，再多探索幾步`。跟著水聲走 → 岔道越走越濕，最後是一道從石縫沖下來的瀑布，從瀑布後面鑽過去，走進一條很長很長的洞——「洞的另一頭，有松樹的味道。」 |
| **戰鬥：失控的礦車** | 倒在地上的礦車，車斗裡裝滿石頭，車輪還在慢慢地轉；「它很怕穿刺」，14 傷害把礦車打翻出鐵軌，「四個輪子朝天，轉了很久很久才停下來」。翻倒的礦車底下壓著一個生鏽的工具箱 |
| **敲石壁聽聲音** | 石壁上有一條一條亮亮的紋路，綠的、紅褐色的，「敲一下，聲音很脆」。行為選項常是 `往滴水的聲音那邊摸過去｜跟著腳底下的鐵軌摸過去｜往有風的地方摸過去` |
| **合成：燃燒瓶** | 「把破布塞進燈油瓶口，留了一截在外面。現在，它是一顆燃燒瓶了。」→ 得到「燃燒瓶」 |
| **深度：淺層** | 場景標題固定帶「深度：淺層」，暗示還有更深處的階段、 |
