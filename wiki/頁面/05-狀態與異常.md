# 05 狀態與異常

[← 回目錄](README.md)

遊戲的負面狀態叫「**症狀**」。畫面會在道具說明旁直接寫出效果與治療方式，
本頁照抄原文並分類。

## 一、症狀一覽

### 1-1 原有症狀（8 種）

| 症狀 | 效果 | 治療 |
|---|---|---|
| **扭傷** | **力量 -1、敏捷 -1**；戰鬥中**逃跑 -2**；每走一步都在痛 | 繃帶、急救包、或好好休息 |
| **出血** | 傷口一直在滲血：**每走幾步、每過幾個回合都有機率失去 1 點體力** | 過一陣子會**自己止住**；繃帶或急救包能**立刻止血** |
| **感染**（紀錄常被 OCR 讀成「染」） | **體質 -2**；傷口在發燙 | 抗生素或急救包（拖太久會惡化成**高燒**） |
| **咳嗽** | **體質 -1、魅力 -1**；戰鬥中**逃跑 -1**；吸了太多髒空氣，咳個不停 | 杏仁水或好好休息；**戴著防毒面具就不會吸進髒空氣**（拖太久會惡化成**肺部發炎**） |
| **失溫** | **力量 -1、敏捷 -1**；戰鬥中**先攻 -2**；冷到手指都不聽使喚 | 喝點熱的（熱杏仁水）或好好休息；**穿著保暖衣物就不會失溫**；急救毯、**毛線手套可完全預防**（拖太久會惡化成**凍傷**）；完整原文見 §1-5 |
| **虛弱** | **力量 -1、體質 -1**；戰鬥中**傷害 -1**；吃了太多不會腐爛的麥子，身體好像比昨天輕了一點 | **罐頭、皇家口糧** |
| **貧血** | **力量 -1、體質 -1**；戰鬥中**先攻 -1、逃跑 -1**；流了太多血，站起來眼前會發黑 | **罐頭、熱湯、皇家口糧**或好好休息 |
| **耳鳴** | ⚠ **未找到完整數值說明**，僅見 `陷入「耳鳴」` 實例 | 離開噪音源、耳塞（待驗證） |

> 「『來得太早了』**壓得人喘不過氣。理智 −1**」（至少出現 4 次）

**（3）惡化鏈：拖太久 → 「出口就在那裡」**

> 「『來得太早了』**拖太久了——惡化成「出口就在那裡」**」

- 原文（杏仁水的「治得好」欄）：「**扭曲的視覺**：敏捷 −1、感知 −2。看出去的走廊全都是彎的，一圈一圈地繞，地板好像斜的，站都站不穩。頭痛、想吐，每一步都可能失去 1 點理智。**喝杏仁水會好一點。**」

- ⚠ 只知道「**杏仁水會好一點**」，**不是「治好」**——是否會完全解除**待確認**；也還沒拍到它的症狀面板。

**本批出現、但既有 Wiki 已收錄（不重列）**：`失落`、`疑神疑鬼`、`被注視`（鎮靜劑的「治得好」欄）。

## 二、症狀的惡化鏈

症狀放著不管會**升級成更嚴重的版本**。舊頁只知道「感染→高燒」「咳嗽→肺部發炎」，本次補齊五條：

```
感染 ──拖太久──▶ 高燒 咳嗽 ──拖太久──▶ 肺部發炎
失溫 ──拖太久──▶ 凍傷 中毒 ──拖太久──▶ 毒素擴散
疲憊 ──拖太久──▶ 精疲力竭
來得太早了 ──拖太久──▶ 出口就在那裡 ← 第七條（第四批新增）
```

> ⚠ 終點「**精疲力竭**」目前只在「疲憊」的說明中被提及，尚未看到它的數值與治療原文。
> ⚠ 另有第六條**候選**：`輻射灼傷 ──拖太久──▶ 急性輻射症候群`（見 §1-6，尚未確認）。
> **「來得太早了 → 出口就在那裡」是第七條確定的惡化鏈**（§1-7）。

另外出現**不列入症狀表的戰鬥減益**：

| 減益 | 效果 |
|---|---|
| `暈眩中` | 錯過下一次行動 |
| `被壓制住了` | 會錯過下一次行動 |
| `腐蝕 -1 / -2` | 防禦下降 |

### 2-1 別把「難度」誤認成症狀或計量條（`惡夢` ×1.7）

第四批的場景標題常寫成 `### 第 2 層《惡夢《QWERTY COMES ．OOOOO《區域：霧裡的方塊《岔路`。
其中 **`惡夢` 是「難度」，不是計量條、也不是症狀**：

| 字串 | 判定 | 證據 |
|---|---|---|
| `惡夢` | **難度 ×1.7**（與既有「困難 ×1.4」同類） | 結算寫 `難度「惡夢」× 1.7` |
| `QWERTY COMES ○…○` | **計量條**（4～6 格，會變動） | |
| `被注視 ○…○` | **計量條**（5～7 格）——⚠ 與症狀「被注視」**同名但不同東西**，不要合併 | |

> ⚠ **重要區分**：`惡夢` 那格**後面可以沒有方塊**（`第 1 層丨困难丨岔路`），
> 方塊只跟著 `QWERTY COMES`／`被注視`／`崩塌`／`困意`／`它的聲音` 這類**計量條名**。
> 詳細的計量條與區域名清單見 [02 戰鬥系統 §十一](02-戰鬥系統.md#十一計量條難度與區域名)。
>
> ⚠ `QWERTY COMES` 的格數語意（4～6 格代表進度還是危險度）紀錄中沒有說明，不臆測。

## 三、症狀的三個共通規則

1. **症狀會扣屬性。** 扣的是屬性**總值**，所以會連帶影響**所有用該屬性的檢定**。
 - 例如「感染」體質 -2 → 體力上限與所有體質檢定一起變差。
 - 畫面會顯示 `智力 1 - 2 = -1` 這種負數結果。

2. **症狀會惡化。** 放著不管會升級：
 `「染」越來越糟了——再不處理，會惡化。`

3. **治療是「順便」的。** 吃對東西會同時恢復資源並治好症狀：
 - 罐頭 → `飢餓 +5、治好「虛弱」「貧血」`
 - 杏仁水 → `理智 +3、口渴 +3、治好「感染」「咳嗽」等`
 - 繃帶 → `體力 +3、治好「扭傷」「出血」`
 - 急救包 → `體力 +6、治好「扭傷」「感染」「出血」等`

> **實用結論**：繃帶／急救包治「外傷類」，杏仁水治「吸入／感染類」，罐頭治「營養類」。
> 急救包的治療範圍最廣，是背包首選。

## 四、理智傷害（另一條血線）

戰鬥與恐怖場景會直接扣**理智**，和體力是兩條獨立的血線：

| 來源 | 紀錄 |
|---|---|
| 敵人重擊 | `重擊！！體力．9、理智．2` |
| 尖叫攻擊 | `體力．5、理智．1、陷入「耳鳴」` |
| 恐怖景象 | `看久了，那塊綠色的招牌好像在眨眼。別過頭去，眼睛裡都是綠色的殘影。理智．2` |
| 鏡子事件 | `體力．1、理智．2` |

減免方式：
- **毛線帽**：**戰鬥中**理智傷害 -1
- 特殊道具：`戰鬥中理智傷害 -1、魅力 +1、技能：放首歌`
- **碑石護符**（飾品）：**理智傷害 -1，戰鬥外也有效** ⭐
由 `方尖碑碎片 ＋ 繩子` 合成（見 [04 物品與裝備 §十二](04-物品與裝備.md#十二合成表工作台)）

> ⚠ **大多數理智傷害減免都只寫「戰鬥中」**——毛線帽、防毒面具、煤油提燈、
> 獸牙項鍊、隨身聽、冠軍腰帶都是。
> **碑石護符是目前唯一「戰鬥外也有效」的**，所以連**事件／場景讀到的理智傷害**也能減。
> 這一條是 2026-10-14 玩家提供的遊戲內說明。
