# 07 事件與場景

[← 回目錄](README.md)

這一頁說明「非戰鬥」的部分：選項怎麼讀、事件有哪些型態、什麼東西會影響你能不能選。

## 一、選項（`O` 行）怎麼讀

選項以 `｜` 分隔，**括號內就是這個選項要擲的檢定**：

```
O 沿著那面摸起來特別熱的牆走｜往舞廳盡頭那個拉著布幕的舞台走
O 沿著接縫找開門的地方（知 難度16）｜靠著牆取暖
O 搜搜看身上有什麼（知 難度13）｜檢查死因（智力 難度16）｜替這個人闔上眼睛，蓋上外套
```

- **沒有括號** = 不用擲骰，直接生效。
- **有括號** = 需要通過該屬性檢定才能得到好結果。
- 選項數量常見 2～4 個，也有單一選項（劇情強制）。

### 特殊標記

| 寫法 | 意思 |
|---|---|
| **`（只有你察覺到）`** | **隱藏選項**，只有感知型／特定角色看得到。例：`（只有你察覺到）走廊的盡頭有兩扇一模一樣的門` |
| **`* 機械維修`** | **技能專屬選項**，擁有該技能才能選。原文：「『機械維修』的選項都能選」 |
| **`女智力 1 以下`** / `女力量 3+` / `女體質 5+` | **角色／屬性限定選項**。`女` 是被 OCR 讀成字的**角色頭像圖示**，所以這行是「某角色（滿足條件）才能選」 |
| **`女小小的翅膀`** | 該角色擁有翅膀才能選（滑翔／飛過去） |
| **`你自己的選擇：你選了就算數`** | **單人模式**下不用投票，直接生效 |
| **`隊伍決定 0 「…」（知 難度13）`** | **多人投票**，通過檢定才成立 |
| **`先不走，再多探索幾步`** | 可以**主動不推進**，留下來多探索（通常是為了補資源） |

> 由於「女」是頭像圖示，紀錄中大量選項的「女…」前綴其實代表
> **多人的場合下，這個選項綁定某個特定角色的能力**——這是本作多人協作的核心：
> 不同角色會**看到不同的選項**。

## 二、事件型態

| 型態 | 說明 | 例子 |
|---|---|---|
| **岔路** | 最常見的節點，2～4 個方向 | `往右邊的走廊走｜跟壁紙上的箭頭走` |
| **戰鬥** | 遭遇敵人，進入回合制 | 見 [02 戰鬥系統](02-戰鬥系統.md) |
| **商店** | 自動販賣機，只收硬幣 | `只收硬幣，不找零` |
| **遺物／屍體** | 搜索可獲得道具與線索 | `沒有傷口的屍體`、`別人留下的東西` |
| **鏡像／倒影** | 鏡子、水面倒影，通常伴隨理智傷害 | `三面鏡子`、`對著倒影擺出拳擊的姿勢` |
| **聲音** | 嗡嗡聲、鈴聲、音樂、歌聲、尖叫——**聲音的方向就是線索** | `往歌聲最大的那一邊走`、`朝嗡嗡聲最大的地方走` |
| **障礙／屬性門檻** | 用屬性硬闖 | `撞倒那面石膏牆`（力量）、`從洞裡鑽過去（敏捷 難度17）` |
| **交易** | 花硬幣或留下東西 | `投一枚硬幣試試（1）`、`留下一些東西當謝禮（每人 1）` |
| **休息** | 睡覺／守夜，恢復資源但有風險 | `閉上眼睛睡一覺｜守夜，睡` |
| **NPC** | 陌生人、小孩、守門人 | `哭著的小孩`、`有人守著的門` |
| **特殊機關** | 需要特定技能或工具 | `修好這台電腦，看看還有什麼 * 機械維修`、`用繩子加固再過（智力 難度14）` |

### 事件進行中的限制

> 「**事件進行中，暫時不能整理背包。**」

## 三、出口與推進

- 推進會累加 `出口進度 X / Y`，滿了就離開這一層。
- 出口的表現形式各層不同：`推開那扇玻璃門`、`走那道生鏽的樓梯`、`爬下去`、`跟著地上的輪胎痕走`。
- 部分事件會**提示出口方向**：
 `有風從縫裡灌進來——出口不遠了。`、`空氣在流動——出口應該就在附近了。`
- 走出去時結算經驗與記憶碎片：
 - `已經走過 8 層了——你：經驗 + 8`
 - `（走出了這一層——這段路的記憶留了下來：每個人的記憶碎片 + 5）`

### 記錄中斷

切到別的瀏覽器分頁時，記錄器會暫停並寫一行 `>` 註記。
這不是遊戲機制，但**看紀錄時要注意**：斷點前後可能跳過了一小段。

## 四、遊戲系統訊息

不屬於遊戲世界觀的提示，例如：

- **版本更新**：「遊戲有新版本了！這一局玩完之後，重新整理網頁就會更新（舊版 3 天內照樣拿得到記憶碎片）」
- **房間相關**：「複製房號」「回主選單按『開房間』」
- **新版本獎勵寬限**：舊版在 3 天內仍可獲得記憶碎片

## 五、值得記錄的敘事片段

這些場景展示了遊戲的氣氛，也是補全世界觀的線索：

- **許願池**：「丟一枚硬幣下去，許個願」→ 硬幣飛回來，黏著一張寫了方向的紙條。
 「只是從那之後，一直覺得洞裡有東西記住了自己。」
- **不要相信回聲**：柱子上原子筆寫的警告，最後一筆拖得很長。
- **全員迷失的收尾**：很久以後，新的流浪者撿到你的背包、寫著名字的紙條、沒電的燈，把名字念了一遍。
- **我讀過這一層**：NPC 靠論壇文章的記憶指路——「論、論壇上……沒寫這一段——」。

## 六、第二輯新增的事件結構

### 6.1 委託系統（跨樓層任務）

第二輯出現了明確的**任務鏈**，由特定 NPC 發布，需要跨樓層完成後回報：

| 委託 | 路線 | 獎勵 |
|---|---|---|
| **最高的樓頂** | Level 10 探勘隊帳篷接 → 到 Level 11 爬上最高的樓頂插下測量標 → 回 Level 10 覆命 | 全員**經驗 +2、各得 15**，並取得「手繪地圖」「厚外套」 |
| **跑進管子裡的貓** | Level 1 接 → Level 2 找橘貓「南瓜」 ||
| **三座中繼站**（★★★★☆） | [Level 699「蔚藍深淵」](06-樓層圖鑑.md#level-699-蔚藍深淵) 的 Astasia 前哨站接（委託人＝通訊官）→ ① [Level 39「巨物恐懼」](06-樓層圖鑑.md#level-39-巨物恐懼) 找一個夠高的地方　② [Level 154「霓虹車站」](06-樓層圖鑑.md#level-154-霓虹車站) 的月台或屋頂　③ [Level 2](06-樓層圖鑑.md#level-2-管道夢境) 的管線走廊 | （尚無資料） |
| **向陽花的種子** | Level 11 滿是花盆的陽台 ||

- 委託**可以放棄**：`投票放棄「流浪商人的信」（答應了的事沒做完，會有點過意不去）`。
- 完成時會有獨立的碎片獎勵（例如 `（委託完成）…記憶碎片 +12`）。

### 6.2 分歧結局點（在樓層中途選擇結束）

**Level 10「豐收麥田」**的泥土路分岔處可以直接結束這一局：

> 看著谷倉看了很久：「**——我們可以住在這裡。有水、有麥子、有屋頂。**」
> 沒說話，只看著手裡那截一直沒有枯萎的麥穗。

選項：`住進那座谷倉`（**結束冒險：在這裡安頓下來**）／`沿著路繼續走`／`先不走，再多探索幾步`。

### 6.3 限時抉擇

**Level 69「希爾伯特旅館」**出現倒數計時的選項：`挑戰者`——畫面從 **10 倒數到 1 秒**，逾時視同放棄。
這是目前唯一觀察到的**即時壓力**事件。

### 6.4 出口的軟性限制

- **走到出口後還能再探索**：`先不走，再多探索幾步`（Level 499 可再多走 **2 步**）。
- **區域轉換不計進度**：走進 Level 36 的「航廈深處」時明說
 「**剛走進新的區域：這一段不算出口進度。**」
- **最後回合提示**：`最後一回合了——出口就在附近！`

### 6.5 大成功的「額外收穫」

除了傷害骰加倍，大成功在事件中會給另一條獎勵線：

- `看出了一條近路（這一段出口進度多 +1）`
- `從這次學到了一點東西（經驗 +1）`
- `大成功的額外收穫——得到「巧克力」`

### 6.6 「睡著」是一種移動方式

**Level 19「深淵旅館」**的兩處場景都以**在床上睡著**作為離開方式，醒來時已身在另一間旅館：

> 聽說在很冷的房間裡睡著，會在別的地方醒來。

### 6.7 樓層狀態欄＝關卡機制

場景標題中間那一格（見 [01 核心機制](01-核心機制.md#場景標題的完整語法)）其實就是**樓層的動態機制**：

| 狀態欄 | 樓層 | 作用 |
|---|---|---|
| `深度：淺層` | Level 300 礦坑 | 深度分層 |
| `溫度：還好` → `溫度：零下四十度` | Level 19 深淵旅館 | 掉溫後反覆觸發**體質難度 18** |
| `漂遠了．．．OOO` | Level 7 深海恐懼 | 漂離計量條 |
| `地方：河岸` → `地方：上游` | Level 173 永無止境的河 | 位置 |
| `季節：灰色的草原` | Level 35 第零天 | 固定季節 |
| `區域：球道區` → `區域：餐廳和酒吧` | Level 499 保齡球館 | 分區 |
| `時間：白天` | 多層 | 日夜 |
| `死寂 ． OOOOOO` | Level 7 死寂 | 噪音計量條 |

### 7.1 Level 0「大廳」（場景標題記為 `第 1 層`／`第 3 層`）

> ⚠ Level 0 在本批出現**兩輪**：`第 1 層`（第 1 輪）與 `第 3 層`（第 2 輪）。少數場景（馬尼拉房間）兩輪都出現，內容一致。

| 場景名 | 做什麼 | 檢定 | 後果 |
|---|---|---|---|
| **Y 字形的走廊** | 走廊在前面分成兩條，像一個 Y 字。左邊跟平常一樣（黃色壁紙、嗡嗡響的燈管）；右邊的燈暗得不正常、飄出很淡的霉味，牆好像也比較高 | 無檢定（`走左邊`／`走右邊`） | 走左邊＝「一切都跟平常一樣——平常得讓人安心」 |

### 9.5 Level 37.6「真正的永恆」

| 場景名 | 做什麼 | 檢定 | 後果 |

| **對講機** | 扶手上綁著一台快沒電的對講機，重播一段錄音 | `聽完一次就關掉` | 錄音：「——十一公里。氧氣還夠——我看到了——又是一片天花板。上面有字——」 |

> 濕滑磁磚（「跑著跑著，摔進了紅色的水裡」）；**`時間感` 計量條**；
> 「**剛走進新的區域：這一段不算出口進度。**」
