## 3. 四份新契约（这是整份方案的核心）

### 3.1 `manifest.json` — 每场次的出生证明

```json
{
  "sid": "backroom-20261029-125010",
  "startedAt": "2026-10-29T04:50:10Z", "endedAt": "2026-10-29T05:27:26Z",
  "recorder": { "scriptSha": "…", "ocr": "zh-Hans-CN", "interval": 0.8, "layout": "partitioned" },
  "host": { "machine": "HX", "screen": "1606x929",
            "window": { "hwnd": 123456, "pid": 12332, "rect": [917,231,2523,1160] } },
  "rules": { "contract": "1.0.0", "idPolicy": "id|name", "fontSafe": ["夭→天","潦→流"] },
  "inputs": { "structuredSha": "…", "frames": 2753 },
  "outputs": { "floors": 2, "events": 10, "rejected": 1, "blocking": 0 }
}
```

治的是：`pid=0`、规则版本不可知、事后无法回答“这条是哪个规则版本产的”。

### 3.2 `identity.json` — 楼层身分的唯一权威

```json
{ "floors": [
  { "key": "1|停车区", "id": "1", "name": "停车区", "rawName": "停车区”",
    "entered": [ { "frame": 2438, "ts": "…", "source": "title×2" } ],
    "conflicts": [ { "name": "停电的楼上", "frame": 2685, "why": "单帧" },
                   { "name": "霓虹车站", "frame": 138, "why": "正文标题行，非 title 区" } ] }
] }
```

三条硬规则：

- **只有 title 区、连续 2 帧一致**才能新增一层。
- 颜色**不再决定楼层编号**（只保留做区域校正）。正文的 `## Level X` 只写进 `conflicts`，不触发转层。
- 被否决的候选**要留著**。现在是静默丢弃 → 幽灵名字污染下游；留著才能解释、才能复查。

### 3.3 `completeness.json` — “已收录”的判准

```json
{ "0|大厅": { "observedEvents": 7, "declaredTotal": 15, "missing": 8,
             "junctions": 0, "combatDropped": 0, "status": "partial" } }
```

状态机：`visited → staged → validated → imported → complete`。
站点显示规则：`complete` = 已收录；`imported` = 已探索（7/15）；其余 = 未探索。
`complete` 条件（全部满足）：doc ≥ 80 字且无截断标记、palette 有本场次 shot+trace、事件数对得上 `declaredTotal` 或显式 `partial`、junctions 自洽。

### 3.4 `_src` — 内容层保留出处

`data/content` 每个条目加：

```json
"_src": { "sid": "…", "frame": 2438, "ts": "…", "confidence": 0.85,
          "contract": "1.0.0", "rule": "event-clean@2026-10-29" }
```

治的是：现在 453 个物品 **0 个**有来源字段，259 个没有 desc——没法判断哪个是游戏资料、哪个是壳。

### 3.5 校验三级（取代现在 error/warning + `ok:true`）

| 级别 | 例子 | 行为 |
|---|---|---|
| `blocking` | schema 型别错（`"x":"false"`）、`selected ∉ actions`、重复 floor key、名称含路径不安全字元、palette 无 trace | 该对象**不写**正式库 |
| `review` | 截断标记、简体残留、低信心、实体名像句子 | 进 staging，人工/规则再判 |
| `info` | 覆盖率缺口、合并了新实体 | 只记录 |

`auto-import` 的放行条件从“errors==0”改成“**blocking==0**”，且 review 数要写进 `auto-import.json`。
