## 3. 四份新契約（這是整份方案的核心）

### 3.1 `manifest.json` — 每場次的出生證明

```json
{
  "sid": "backroom-20261029-125010",
  "startedAt": "2026-10-29T04:50:10Z", "endedAt": "2026-10-29T05:27:26Z",
  "recorder": { "scriptSha": "…", "ocr": "zh-Hans-CN", "interval": 0.8, "layout": "partitioned" },
  "host": { "machine": "HX", "screen": "1606x929",
            "window": { "hwnd": 123456, "pid": 12332, "rect": [917,231,2523,1160] } },
  "rules": { "contract": "1.0.0", "idPolicy": "id|name", "fontSafe": ["夭→天","潦→流"] },
  "inputs": { "structuredSha": "…", "frames": 2753 },
  "outputs": { "floors": 2, "events": 10, "rejected": 1, "blocking": 0 }
}
```

治的是：`pid=0`、規則版本不可知、事後無法回答「這條是哪個規則版本產的」。

### 3.2 `identity.json` — 樓層身分的唯一權威

```json
{ "floors": [
  { "key": "1|停車區", "id": "1", "name": "停車區", "rawName": "停车区」",
    "entered": [ { "frame": 2438, "ts": "…", "source": "title×2" } ],
    "conflicts": [ { "name": "停電的樓上", "frame": 2685, "why": "單帧" },
                   { "name": "霓虹车站", "frame": 138, "why": "正文標題行，非 title 區" } ] }
] }
```

三條硬規則：

- **只有 title 區、連續 2 帧一致**才能新增一層。
- 顏色**不再決定樓層編號**（只保留做區域校正）。正文的 `## Level X` 只寫進 `conflicts`，不觸發轉層。
- 被否決的候選**要留著**。現在是靜默丟棄 → 幽靈名字污染下游；留著才能解釋、才能複查。

### 3.3 `completeness.json` — 「已收錄」的判準

```json
{ "0|大廳": { "observedEvents": 7, "declaredTotal": 15, "missing": 8,
             "junctions": 0, "combatDropped": 0, "status": "partial" } }
```

狀態機：`visited → staged → validated → imported → complete`。
站點顯示規則：`complete` = 已收錄；`imported` = 已探索（7/15）；其餘 = 未探索。
`complete` 條件（全部滿足）：doc ≥ 80 字且無截斷標記、palette 有本場次 shot+trace、事件數對得上 `declaredTotal` 或顯式 `partial`、junctions 自洽。

### 3.4 `_src` — 內容層保留出處

`data/content` 每個條目加：

```json
"_src": { "sid": "…", "frame": 2438, "ts": "…", "confidence": 0.85,
          "contract": "1.0.0", "rule": "event-clean@2026-10-29" }
```

治的是：現在 453 個物品 **0 個**有來源欄位，259 個沒有 desc——沒法判斷哪個是遊戲資料、哪個是殼。

### 3.5 校驗三級（取代現在 error/warning + `ok:true`）

| 級別 | 例子 | 行為 |
|---|---|---|
| `blocking` | schema 型別錯（`"x":"false"`）、`selected ∉ actions`、重複 floor key、名稱含路徑不安全字元、palette 無 trace | 該對象**不寫**正式庫 |
| `review` | 截斷標記、簡體殘留、低信心、實體名像句子 | 進 staging，人工/規則再判 |
| `info` | 覆蓋率缺口、合併了新實體 | 只記錄 |

`auto-import` 的放行條件從「errors==0」改成「**blocking==0**」，且 review 數要寫進 `auto-import.json`。
